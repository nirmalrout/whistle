# React Landing Page Components

This project contains three reusable and responsive React components commonly used in marketing and landing pages.

## Features

* Responsive design for Desktop, Tablet, and Mobile devices
* Data-driven UI using local JSON/JavaScript data files
* Reusable and modular component structure
* Smooth expand/collapse animations
* Mobile-friendly carousel using Swiper.js
* Icons implemented using React Icons
* Easy to replace static data with API responses in the future

---

## Components

### 1. FAQ Section

A reusable accordion component that displays frequently asked questions.

#### Features

* Single item expand/collapse behavior
* Smooth height animation
* Dynamic content rendering from local data source
* Mobile responsive layout

#### Data Source

Data is imported from:

```javascript
src/data/faq.js
```


---

### 2. Comparison Table Section

A feature comparison table used to compare products or services.

#### Features

* Dynamic row rendering from local data
* Expandable rows for additional information
* Smooth expand/collapse animation
* Responsive layout for mobile devices
* Data-driven architecture

#### Data Source

Data is imported from:

```javascript
src/data/comparisonData.js
```




---

### 3. Why Whistle Section

A card-based information section showcasing key product benefits.

#### Features

* Dynamic card rendering
* Equal height cards
* Image placeholders supported
* Mobile carousel implementation
* Swiper.js integration
* React Icons support
* Responsive design

#### Data Source

Data is imported from:

```javascript
src/data/whyWhistle.js
```


---

## Third Party Libraries

### Swiper

Used for creating responsive mobile carousels.

Installation:

```bash
npm install swiper
```


---

### React Icons

Used for accordion arrows, comparison icons, and UI indicators.

Installation:

```bash
npm install react-icons
```
